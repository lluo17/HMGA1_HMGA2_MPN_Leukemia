# GSEA output

Figure 1G was generated with the Broad Institute GSEA Java desktop application, not with an R GSEA package.

The exact ranked-list inputs supplied for the analysis are deposited in `data/GSEA_ranked_lists/`:

- `HMGA1_MF_pos_vs_neg.rnk`
- `HMGA2_MF_pos_vs_neg.rnk`
- `HMGA1_control_pos_vs_neg.rnk`
- `HMGA2_control_pos_vs_neg.rnk`

Complete GSEA-generated result directories can be placed in this folder unchanged. GSEA result folders contain linked HTML, tables, plots, and supporting files; preserving each generated directory intact is preferable to selecting individual files from within it.
