# Data files included in this repository

Only compact analysis inputs/intermediates directly tied to the accepted figures are included here. Large public scRNA-seq count matrices and Seurat objects are not redistributed.

## GSEA_ranked_lists
Exact `.rnk` files used as inputs to the Broad Institute GSEA Java application for Figure 1G.

## GSE122198
- `GSE122198/README.md`: detailed provenance for the Figure 2A Target-seq workflow.
- `GSE122198_extracted_HMGA1_HMGA2_JAK2.xlsx`: extracted Target-seq metadata/expression working table (2,798 cells).
- `GSE122198_grouped_HMGA1_HMGA2.xlsx`: analysis-ready HMGA1/HMGA2 grouping for healthy control (n=678), MF JAK2-WT (n=413), and MF JAK2-mutant (n=1,707) cells, used for the Figure 2A Excel/GraphPad workflow.

## platelet
- `platelet_HMGA1_HMGA2_source.xlsx`: source HMGA1/HMGA2 platelet expression workbook retained for provenance.
- `platelet_HMGA1_HMGA2_log1p.xlsx`: log1p-transformed expression table used for Figure 2B plotting/statistics in GraphPad Prism.
- `synergy.xlsx`: compact diagnosis/HMGA1/HMGA2 table used for the Figure 2C-D high/low biomarker analysis.
